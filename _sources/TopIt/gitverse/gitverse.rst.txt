Gitverse
============

1. Заходим по ссылке: `<https://gitverse.ru/>`_
2. Шаблон репозитория ППС: `<https://gitverse.ru/KAA85/reverse-engineering-demo>`_
3. Инструкция по работе с репозитрием: `инструкция <https://gitverse.ru/KAA85/reverse-engineering-demo/content/master/инструкция-по-работе-с-репозиторием-ППС.md>`_


Регистрация
---------------------

1) Нажимаем ``Начать работу``:

.. figure:: ./image/step_0.png

   Страница регистрации.


2) Войти по ``GigaID``:

.. figure:: ./image/step_1.png

   Регистрируемся при помощи GigaID.

3) Если у Вас нет учетной записи - ``Создать GigaID``:

.. figure:: ./image/step_2.png

   Создать GigaID.

4) Пример регистрации по почтовому адресу **СибГУТИ** (если нет, идем в **ОИТ** и получаем):

.. figure:: ./image/step_3.png

   Регистрация по почте СибГУТИ.

5) На почту придет ``Код подтверждения``, вводим:

.. figure:: ./image/step_4.png

   Код подтверждения на почту.

6) Далее, попросит привязать номер телефона:

.. figure:: ./image/step_5.png

   Привязываем номер телефона.

7) Придет **СМС** с кодом подтверждения, вводим:

.. figure:: ./image/step_6.png

   Код подтверждения СМСкой.

8) Придумать имя пользователя ``Girverse``:

.. figure:: ./image/step_7.png

   Придумать имя пользователя.

9) Вуаля, создали учетную запись:

.. figure:: ./image/step_8_reg_success.png

   Готово.



Создание публичного репозитория в Gitverse
---------------------

0) В самом Getverse довольно подробно расписано как создать свой репозиторий:

.. figure:: ./image/repo_all_steps.png

   Гайд от Gitverse.


**Либо. идем по каждому шагу отдельно**:

1) Нажимаем на кнопку **создания первого репозитория**:

.. figure:: ./image/repo_0_0.png

   Создать репозитрий.

2) Заполняем название Вашего репозитория, его видимость (пиватность) и т.д.:

.. figure:: ./image/repo_0_2.png

   Создание репозитория.


Файл ``README.md`` обычно представляет из себя обчыный текстовый файл, в котором описывают проект. Этот файл автоматически будет отображаться при переходе на Ваш проект.

3) Репозиторий успешно создан. Сейчас в нем присутствует лишь 1 файл: ``README.md``, его содержимое отображается как описание вашего проекта.

.. figure:: ./image/repo_0_3.png

   Репозиторий создан.



Добавление файлов в репозиторий
---------------------


1) Шаблон репозитория ППС: `<https://gitverse.ru/KAA85/reverse-engineering-demo>`_

В этом шаблоне уже есть готовый пример работ РПД, ОС и т.д в формате ``.md``. Скачать его можно 

.. figure:: ./image/repo_0_4.png

   Репозиторий создан.



2) После скачивания архива с репозитрием можно посмотреть на внутренности файлов формата ``MARKDOWN`` или ``.md``:

.. figure:: ./image/repo_0_5.png

   Формат ``markdown``.

Примеры оформлений ``.md`` (можно открывать в ``VsCode``, ``Блокнот``, ``Онлайн-редакторах``): 

- `<https://markdownlivepreview.com/>`_
- `<https://gist.github.com/Jekins/2bf2d0638163f1294637>`_
- `<https://doka.guide/tools/markdown/>`_

Важно помнить, что файлы сохраняются именно в формате ``<имя_файла>.md``.


3) Загружаем измененные файлы в Ваш репозиторий. Сначала находим кнопку ``Загрузить файл`` в Вашем репозитории: 

.. figure:: ./image/repo_0_6.png

   Загрузить файл.



**Далее**, загружаю файл с названием ``test.md``:

.. figure:: ./image/repo_0_8.png

   Сохранить.

Коментарии к коммиту и его описание можно заполнять по желанию.

По умолчанию, ветка используется - ``master``.


**Готово**, файл успешно загружен.

.. figure:: ./image/repo_0_9.png

   Готово.


После открытия файла Вы уже будете видеть отформатированный текст, без спец. знаков разметки: 

.. figure:: ./image/repo_0_10.png

   Результат.
